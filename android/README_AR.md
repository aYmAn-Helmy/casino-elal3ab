# تطبيق أندرويد — كازينو الألعاب

تطبيق Android WebView أصلي خفيف بواجهة لتحديد IP سيرفر CasaOS لأول مرة. بعد إدخال `192.168.x.x:3000` يعرض صفحة `/play` داخل التطبيق ويتصل بـ WebSocket بالسيرفر المحلي.

- `applicationId`: `com.ayman.casinoelal3ab`
- `minSdk=23`، `targetSdk=34`، `compileSdk=35`
- لا يوجد سيرفر سحابي: الجهاز والهاتف على نفس Wi-Fi
- الاتصال المحلي غير مشفر HTTP/ws؛ لا تفتح اللعبة للإنترنت

## إنشاء APK للتجربة
يستطيع GitHub Actions بناء `assembleDebug`، ويُنشر الناتج على GitHub Releases كملف `casino-elal3ab.apk` عند إنشاء tag من نوع `v*`. سكربت `install-casaos.sh` يحاول تنزيل APK الخاص بإصدار `v0.1.1` إلى مجلد CasaOS، وبعدها يعمل الرابط `/download`.

**هام:** APK الحالي إنشائي/تجريبي بتوقيع Debug من بيئة البناء؛ تحديث إصدار جديد قد يتطلب إزالة الإصدار السابق إذا اختلف مفتاح التوقيع. للإصدار النهائي يجب إعداد توقيع release ثابت وسري، ولا تضف أي keystore خاص إلى GitHub.

للاعبين اللي مش عايزين APK، استخدموا رابط `http://SERVER_IP:3000/play` في المتصفح مباشرة.

## أصوات الجرس الجديدة
عندما يضغط اللاعب على الزر المتاح يسمع صوت جرس فوري، وعند فوزه حسب نتيجة السيرفر يسمع نغمة تأكيد منفصلة. لا يصدر صوت إغلاق على بقية الهواتف. الصوت يُولَّد في WebView من Web Audio API، ويمكن كتمه من صفحة اللاعب.
