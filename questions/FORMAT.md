# صيغة ملف الأسئلة (JSON)

احفظ الملف بترميز UTF-8، مثال هيكل فقط (**ليس** سؤالًا أصليًا من لعبة مروان سري):

```json
{
  "questions": [
    {
      "text": "كم عدد أيام الأسبوع؟",
      "answer": "سبعة",
      "category": "معلومات عامة",
      "source": "مثال توضيحي من إعداد المطور",
      "reference": ""
    }
  ]
}
```

يمكن استخدام قائمة مباشرة `[ ... ]` بدل `{"questions":[...]}`. الحقول المطلوبة: `text`, `answer`, `category`. الحقول الاختيارية: `source`, `reference`.

الشروط: 1–1000 سؤال؛ نص السؤال والإجابة حتى 400 حرف، التصنيف حتى 60 حرف، المصدر حتى 120 حرف، المرجع حتى 250 حرف؛ لا تكرار لنفس السؤال. استيراد ملف جديد **يستبدل** القديم.

لا ترفع محتوى تجاريًا محميًا إلى مستودع عام بدون حق نشره. لو عندك نسخة مرخصة من الأسئلة، الأفضل استيرادها محليًا فقط من لوحة المذيع على CasaOS. يتم حفظ البنك في ملف SQLite داخل مجلد بيانات Docker.

الإجابات لا تظهر على شاشة `/screen` أو أجهزة اللاعبين، بل للمذيع بعد تسجيل الدخول فقط.
