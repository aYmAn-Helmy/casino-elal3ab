This audio is used unchanged where available. Credits are also visible on the player page.

The project does **not** claim that this recording is the exact original sound used in Marwan Serry's commercial game. To replace the bell with a recording you own or have permission to use, save the recording as an MP3 file to `/DATA/AppData/casino-party-lan/data/bell.mp3` on CasaOS.

If recording download fails, the game uses an offline Web Audio API synthesizer as a fallback.
