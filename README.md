# Casino El Al3ab 🎮

لعبة جرس ومسابقات جماعية تعمل على شبكة LAN، ومجهزة للاستضافة على **CasaOS / Mini PC**.

> MVP v0.1.0: اللاعبين يفتحوا اللعبة من متصفح الموبايل، المذيع يتحكم في الجولات والنقاط، وكل الضغطات بتتحسم على السيرفر عبر WebSocket. **ملف Android APK غير متوفر حتى الآن.**

## 🎮 تشغيل اللعبة على CasaOS — من الصفر

على Mini PC بتاع CasaOS، افتح SSH ونفّذ الأوامر دي:

```bash
git clone https://github.com/aYmAn-Helmy/casino-elal3ab.git
cd casino-elal3ab
sudo bash install-casaos.sh
```

هيجهّز 1000 سؤال نصي في 11 نوع تلقائيًا، ولوحة المذيع، شاشة النتائج، وتطبيق الموبايل. السكربت بيطبع لك IP الجهاز وكلمة مرور المذيع العشوائية بعد التثبيت.

- `http://CASAOS_IP:3000/play` — اللاعب
- `http://CASAOS_IP:3000/admin` — المذيع
- `http://CASAOS_IP:3000/screen` — التلفزيون
- `http://CASAOS_IP:3000/download` — APK لو نزلت نسخة الإصدار على السيرفر

التثبيت الأول يحتاج إنترنت لبناء Docker وتنزيل APK من GitHub Releases؛ اللعب بعدها كله على LAN. التطبيق Android يتطلب إدخال IP:PORT للسيرفر أول مرة. **[الدليل الكامل للمبتدئين](CASAOS_START_HERE_AR.md)**.

## مكونات المشروع
- Node.js 24 + WebSocket (`ws`) للسيرفر والجرس
- SQLite لتخزين اللاعبين والنقاط
- واجهات ويب للاعب والمذيع وشاشة النتائج
- Docker وDocker Compose للتشغيل على CasaOS

## تشغيل سريع على Mini PC / CasaOS

```bash
git clone https://github.com/aYmAn-Helmy/casino-elal3ab.git
cd casino-elal3ab
cp .env.example .env
# غيّر ADMIN_PIN إلى سر قوي في ملف .env
sudo mkdir -p /DATA/AppData/casino-party-lan/{data,apk}
sudo chown -R 1000:1000 /DATA/AppData/casino-party-lan/data
docker compose up -d --build
```

بعد التشغيل: `http://SERVER_IP:3000` ثم `/play` للاعب و`/admin` للمذيع و`/screen` للشاشة.

لظهور التطبيق داخل **CasaOS**، ابنِ الصورة محليًا أولًا ثم استورد `docker-compose.casaos.yml` من Custom Install.

**اقرأ [دليل التثبيت بالعربي](README_AR.md) للمزيد**، و[توثيق البروتوكول](API.md).

## الأمان والتطوير
- لا ترفع ملف `.env` أو أي مفاتيح خاصة إلى GitHub.
- غيّر `ADMIN_PIN` النموذجي قبل التشغيل، ولا تعرض المنفذ 3000 على الإنترنت.
- طريقة احتساب السبق: أول ضغطة صحيحة **تصل للسيرفر** تفوز؛ ليست قياسًا مؤكدًا للحظة الضغط على الأجهزة.
- تثبيت متطلبات Docker أول مرة يتطلب الإنترنت، لكن اللعب على LAN لا يحتاج الإنترنت.

## بنك الأسئلة (1000 سؤال جاهز)
الريبو يحتوي على **1000 سؤال نصي للعب الجماعي** موزعة على 11 نوعًا (290 كلمات معكوسة، 230 عواصم، 200 كلمة في أغنية، 60 معلومات عامة، 50 وصف أكلة، 30 وصف مكان، 25 وصف مهنة، 50 أمثال شعبية، 25 أفلام ومسلسلات، 20 إفيهات أفلام، 20 غنّي لمطرب معين). الأسئلة ليست من لعبة مروان سري الرسمية؛ تشمل بعض الأمثال المتداولة وإشارات قصيرة لأعمال سينمائية. تُضاف الأسئلة تلقائيًا عند أول تشغيل فقط إذا كانت قاعدة الأسئلة فارغة، دون استبدال أي بنك أسئلة موجود. لاستبدالها بأسئلة لديك حق استخدامها، ادخل `/admin` وسجّل الدخول، ثم ارفع ملف JSON فيه من 1 إلى 1000 سؤال بالشكل الموجود في `questions/FORMAT.md`. المذيع فقط يرى الإجابة، بينما شاشة العرض تعرض السؤال والتصنيف. الأسئلة تتخزن في SQLite وتبقى بعد إعادة تشغيل الحاوية.
